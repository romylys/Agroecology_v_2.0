
## Варіанти
- Основний — дизайн «Польовий атлас» (корінь репозиторію).
- `agroeco-v1/` — попередня версія теми (v1), повний самодостатній сайт.

## Головна: два варіанти
- `index.html` — варіант 1 (поточна головна, шаблон `front-page.php`).
- `golovna-v2/index.html` — варіант 2 за макетом «Польовий атлас» (шаблон `front-page-v2.php`: hero з ізолініями, факти, швидкі посилання, новини, видання в один рядок, підрозділи, моніторинг, аспірантура, журнали, мережа).

Варіант 2: після блоку новин іде блок «Оголошення» (`section.ah-ann`, у WP — останній активний запис CPT «Оголошення», той самий модуль, що в `front-page.php`).
Далі — `section.ah-ann-next`: головні новини + «Найближчі події» (модуль `.h2` із поточної головної, у WP — той самий фрагмент `front-page.php`).

## Варіант 4 головної (`golovna-v4/`, шаблон `front-page-v4.php`)
Шапка, головне меню й футер — зі світлої теми «Польовий атлас» (смуга контактів, шапка з печаткою ІАП, меню з випадними списками `ul.menu.v4-menu > li.menu-item > ul.sub-menu`, `wp_nav_menu` theme_location primary). Тіло — як у варіанті 2. Перемикач світлої/темної теми (`html[data-theme="dark"]`, вибір зберігається в localStorage); кольори — через CSS-змінні у `:root`.
