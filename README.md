
## Типи новин
Сторінка `novyny/typy-novyn/` — каталог 10 типів матеріалів (оголошення, подія, лекція, звіт, фоторепортаж, ювілей, вступ, набір статей, нове видання, аналітика)
з переліком модулів і реальними прикладами з agroeco.org.ua. Усі типи мають єдине оформлення статті (стаття + бічна колонка «Коротко / Документи / Контакти / Інші новини»);
тип змінює лише набір модулів у тексті (`<!-- module: … -->`). У WordPress: таксономія `news_type`, модулі — блоки Gutenberg/ACF.
