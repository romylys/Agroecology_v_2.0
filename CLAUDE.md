# Правила для цього репозиторію (тема Agroeco 2.0)

- **Сітки з картками завжди заповнюють ширину сторінки** на будь-якому дисплеї без неповних рядків: стрічки (видання, новини) мають `data-fill` (`js/script.js` ховає зайві картки або розтягує їх), контентні сітки вміст не ховають.
- Після змін перевіряти без горизонтальної прокрутки на 360, 390, 768, 1024, 1366, 1920 px.
- Стилі — тільки `css/style.css`, скрипти — `js/script.js`, картинки — `images/`; кожна сторінка — власна папка з `index.html`.
- Оформлення сторінок новин — єдине (стаття + бічна колонка); тип новини змінює лише модулі в тексті.
